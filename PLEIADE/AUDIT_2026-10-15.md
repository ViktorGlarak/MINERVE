## 3. Par instance

### pleiade-platform (orchestrateur, portail, catalogue)
- **Bloquant** : terminal WebSocket sans auth (§1-1). Secret de cookie par défaut `pleiade-dev-cookie-secret` si `COOKIE_SECRET` absent (`config.ts:114`) — la session du portail (sub, groupes) est forgeable ; non vérifié sur le serveur. Identifiants par défaut en clair dans `docker-compose.prod.yml` et `config.ts` (root MariaDB, admin Keycloak) — à retirer, échouer si la variable manque.
- **Gênant** : mots de passe des comptes de zone en clair (`orch_user_passwords.raw_password`, renvoyés par `GET /api/zones/:zone/users`, copiés dans les sauvegardes, poussés dans un attribut Keycloak `rawPassword`). Cookie du dashboard sans `Secure`, comparaison HMAC non à temps constant. Scripts tiers depuis des CDN sans SRI (xlsx 0.18.5 vulnérable, xterm) : tombent sans Internet. `npm test` cassé sous Windows (syntaxe POSIX). `.env.prod.example` incomplet.

## 4. Plan proposé (ordre)

1. **Sécurité immédiate** (platform, social, messagerie) : fermer `/ws/terminal` (session + rôle + Origin), retirer `migrator.env` de l'historique et **changer les mots de passe concernés**, corriger la pipe XSS + CSP sur social, journaliser/refuser la lecture sous emprunt d'identité dans la messagerie, retirer les valeurs par défaut (cookie, root, admin) de la plateforme.
2. **Anonymat et noms réels** (melmil, admin → cockpit, social) : ne plus journaliser `par.qui` avec un demandeur ; `auteurId` seul dans `stats/cellules` ; filtrer `operateur` dans users/accounts/retex ; supprimer `/api/zone/comptes`.
3. **Socle commun** : middleware Traefik `headers` ; `memeOrigine` et vérification `azp` dans chaque app ; resynchronisation des copies (BarreZone avec « Animation » et `ia`, discovery, Modal, thème) ; BarreZone remise dans le Cockpit.
4. **Moteur IA** (15.14) : exemple d'invite, contexte rechargé à chaque cycle, try/catch autour du modèle (messages privés, lot), quotas dans `etat`, `pourquoi` dans le select, palette commune aux deux cartes, notes .8 → .13.
5. **Robustesse** : bornes (`take`) sur retex (social, press), export d'analyse, journal ; cadences et visibilité (cockpit 15 s, admin 30 s) ; lots d'envoi LEAC ; quota disque MELMIL ; explorateur webserver.
6. **Infra** : commiter l'état réel du serveur, protéger registre et dashboard Traefik, SAN du wildcard, `.gitignore` des clés de zone.
7. **Docs et ménage** : notes de version jusqu'au dernier tag, README par app, branches fusionnées supprimées, scripts jetables de LEAC rangés, sentinel/migrator/vanilla-cockpit sortis de social.

## 5. Non vérifié
Le `.env` et l'état réel du serveur (Traefik, certificats, registre, `COOKIE_SECRET`) ; l'app `partage` (pas de dépôt local) ; le comportement de l'attribut Keycloak `rawPassword`.
