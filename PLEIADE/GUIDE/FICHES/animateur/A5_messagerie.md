# Faire parler des avatars dans la Messagerie

> Créez une discussion de groupe entre avatars et écrivez-y au nom de l'un d'eux.

## Ce que vous allez apprendre
- Écrire **au nom de** un avatar
- Créer un canal, un groupe ou une conversation privée
- Reprendre son identité

## Pas à pas
1. Sous votre nom, ouvrez le sélecteur (« Vous-même ») : **Écrire au nom de** → **Rechercher une identité** → choisissez un avatar.
2. **Nouvelle conversation** : **Forme** **Groupe**, **Titre**, **Participants**, puis **Créer**.
3. Écrivez dans **Écrire un message…** puis **Envoyer** : le bandeau rappelle « Vous écrivez au nom de … ».
4. **Reprendre mon identité** pour revenir à votre compte.

## Bon à savoir
- Un canal **en diffusion** : seuls ses administrateurs publient (les joueurs le lisent).
- Les joueurs voient les conversations auxquelles ils participent et les canaux qu'ils rejoignent.
