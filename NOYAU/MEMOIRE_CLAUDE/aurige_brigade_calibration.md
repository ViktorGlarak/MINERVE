# Doctrine de calibration AURIGE — Niveau brigade

> **Document vivant** — à enrichir au fil des exercices, retours de formation, nouvelles idées.
> Référence transversale pour MASTAURIGE, GUILLAUME, AURIGE, PENSEUR, SCÉNARISTE, EXPERT_INFLUENCE.

**Why:** Les injects D+31→D+34 d'AURIGE 2BB ont été produits à un niveau trop élevé (niveau division / stratégique). AURIGE entraîne un PC de niveau **brigade**. Il faut corriger le tir à partir de D+35 et ancrer cette doctrine pour tous les exercices futurs.
**How to apply:** Avant toute création d'inject pour un exercice AURIGE, vérifier qu'il touche directement la ZO de la brigade et les responsabilités du PC brigade.

---

## 1. Bilan critique D+31→D+34 AURIGE 2BB

### Ce qui était trop haut niveau (à éviter à l'avenir)
- Discours de chefs d'État (Olamao, Pallesson, Youkachenko, Rutte) → niveau stratégique
- Articles de médias nationaux/internationaux (TV4, Today Mercure, BC1) sur la guerre → niveau opératif/stratégique
- Déclarations du SG OTAN / SG ONU → niveau stratégique
- Mobilisation générale d'une armée nationale → niveau stratégique
- Escalade diplomatique Mercure ↔ Ruthnia Bella → niveau stratégique

### Ce qui était utile au niveau brigade
- @clambroise55 (civil local Lorraine, 03 72 67...) → ✅ niveau population locale
- Courriers des maires → ✅ niveau brigade si la brigade est concernée
- Tract MAF diffusé sur zone → ✅ si ciblé ZO brigade
- Sniper dans la ZO → ✅ niveau brigade

### Le bon équilibre (règle canonique)
> Un PC brigade reçoit les injects politiques/stratégiques **en CADRAGE SEULEMENT** (1-2 par semaine max) pour contextualiser. Tous les autres injects doivent toucher DIRECTEMENT sa ZO, ses soldats, sa relation avec la population locale.

> Lorraine — ces villes doivent apparaître nommément dans les injects. Variété géographique obligatoire.

## 4. Structure thématique recommandée (arc brigade)

> Un PC brigade gère des thèmes précis. Les injects doivent s'inscrire dans ces thèmes.

| Thème brigade | Injects correspondants | Phase tactique |
|---|---|---|
| **Relations avec la population** | Plainte maire, sermon, RS humiliants, journal local | D+31→D+35 (montée en tension) |
| **Sécurité des arrières / rear** | Vandalisme, présence pro-MER, tags, tracts | D+31→D+38 (permanent) |
| **Renseignement HOS** | Signalement personnel suspect, pages LinkedIn fictives | D+33→D+40 (criblage) |
| **Gestion de l'information** | Radio locale, journal, RS — veille médiatique locale | Permanent |
| **Pression morale sur les soldats** | RS humiliants, témoignages, tracts démoralisants | D+33→D+40 |
| **Ordre public local** | Manifestation, drapeau, graffitis | D+35→D+38 (post-climax) |

## 6. Connexion avec doctrine VIGINUM Storm-1516

> Combiner les types d'injects brigade avec les 4 phases Storm-1516 (ANALYSTE MERCURE).

| Phase Storm-1516 | Injects brigade correspondants |
|---|---|
| **Phase 1 — Primo-diffusion** | Tract dans la rue, tweet civil témoin, signalement local → source primaire bas bruit |
| **Phase 2 — Blanchiment** | Article journal local qui "rapporte" ce que les civils disent → source secondaire crédible |
| **Phase 3 — Amplification** | RS humiliants partagés, radio locale qui reprend → multiplication canaux |
| **Phase 4 — Reprises institutionnelles** | Courrier du maire, déclaration notable → reprise "officielle" locale |

**Règle d'or :** Pour chaque thème brigade, concevoir une chaîne minimum de 3 injects sur 2-3 jours suivant les 4 phases. Le PC brigade doit voir la chaîne se construire et comprendre qu'il est ciblé.
