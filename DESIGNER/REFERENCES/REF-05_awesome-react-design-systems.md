# REF-05 — Awesome React Design Systems (jbranchaud)

- **Source** : https://github.com/jbranchaud/awesome-react-design-systems
- **Ingéré** : 2026-09-24
- **Nature** : liste de design systems **implémentés en React**, en trois parties : web, React Native, divers.

## Les plus notables (portés par une organisation)
| Système | Organisation | Caractère |
|---|---|---|
| **Material UI** | (Material Design, Google) | le plus répandu ; très complet, personnalité marquée |
| **Ant Design** | Ant Financial | dense, orienté applications de gestion |
| **Carbon** | IBM | sobre, dense, très documenté, **accessibilité** poussée |
| **Polaris** | Shopify | règles de contenu et de rédaction exemplaires |
| **Blueprint** | Palantir | **applications de données denses** sur ordinateur (tableaux, arbres, panneaux) |

Autres : Atlaskit (Atlassian), Backpack (Skyscanner), Canvas (HubSpot), Garden (Zendesk), Grommet (HP), Lightning (Salesforce), Ring UI (JetBrains), Priceline One, Pluralsight. React Native : React Native Elements, NativeBase, Shoutem UI, Teaset.

## Pour nos projets
- Nos applicatifs (MELMIL, admin, LEAC, cockpit) sont des **outils de travail denses** utilisés par des animateurs sous pression. Leurs cousins les plus proches sont donc **Blueprint** et **Carbon**, pas des vitrines marketing.
- **LEAC terrain** (tablette, hors ligne, en extérieur) relève d'autres critères : grandes cibles, fort contraste, lisibilité au soleil (voir Fitts, REF-06).
