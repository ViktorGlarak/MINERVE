# REF-06 — Laws of UX (Jon Yablonski)

- **Source** : https://lawsofux.com
- **Ingéré** : 2026-09-24
- **Nature** : 30 lois et principes de psychologie appliqués aux interfaces. C'est **la grille de lecture** de DESIGNER pour justifier un conseil.

## Les 30 lois
| Loi | Catégorie | En une phrase |
|---|---|---|
| **Aesthetic-Usability Effect** | heuristique | Un design jugé beau est perçu comme plus facile à utiliser. |
| **Choice Overload** | biais | Trop d'options paralyse. |
| **Chunking** | principe | Découper l'information en groupes qui ont du sens. |
| Cognitive Bias | biais | Erreurs systématiques de jugement. |
| **Cognitive Load** | principe | L'effort mental que demande l'interface. |
| **Doherty Threshold** | heuristique | Au-dessous de **400 ms** de réponse, la productivité s'envole. |
| **Fitts's Law** | principe | Le temps pour atteindre une cible dépend de sa **distance** et de sa **taille**. |
| Flow | cognitif | Immersion totale dans la tâche. |
| Goal-Gradient Effect | biais | On accélère à l'approche du but (barres de progression). |
| **Hick's Law** | principe | Le temps de décision croît avec le nombre et la complexité des choix. |
| **Jakob's Law** | heuristique | Les gens passent leur temps ailleurs : ils attendent que votre site marche comme les autres. |
| Common Region | Gestalt | Des éléments dans un même cadre sont perçus comme un groupe. |
| **Proximity** | Gestalt | Ce qui est proche est perçu comme lié. |
| Prägnanz | Gestalt | On lit l'ambigu sous sa forme la plus simple. |
| **Similarity** | Gestalt | Ce qui se ressemble est perçu comme un groupe. |
| Uniform Connectedness | Gestalt | Ce qui est relié (trait, cadre) paraît plus lié. |
| **Mental Model** | cognitif | L'idée que l'utilisateur se fait du fonctionnement. |
| **Miller's Law** | cognitif | ≈ 7 ± 2 éléments en mémoire de travail. |
| Occam's Razor | principe | À efficacité égale, la solution la plus simple. |
| **Paradox of the Active User** | heuristique | Personne ne lit le mode d'emploi. |
| Pareto | principe | 80 % des effets viennent de 20 % des causes. |
| Parkinson's Law | principe | Une tâche occupe tout le temps disponible. |
| **Peak-End Rule** | biais | On juge une expérience sur son **pic** et sa **fin**. |
| **Postel's Law** | principe | Tolérant sur ce qu'on accepte, rigoureux sur ce qu'on produit. |
| Selective Attention | cognitif | On ne voit que ce qui sert le but du moment. |
| Serial Position Effect | biais | On retient le premier et le dernier d'une série. |
| **Tesler's Law** | principe | La complexité incompressible doit être portée par le système, pas par l'utilisateur. |
| **Von Restorff Effect** | biais | Ce qui diffère du reste est mémorisé. |
| Working Memory | cognitif | Mémoire temporaire de la tâche en cours. |
| **Zeigarnik Effect** | biais | On retient mieux ce qui est inachevé. |

## Points pratiques relevés
- **Fitts** : cibles tactiles **assez grandes**, **bien espacées**, placées **là où on les atteint** facilement.
- **Hick** : réduire les choix quand le temps compte · découper les tâches complexes · **mettre en avant l'option recommandée** · accueil progressif · sans simplifier jusqu'à l'abstraction.
- **Jakob** : l'utilisateur transporte ses habitudes d'un produit à l'autre ; s'appuyer sur les modèles qu'il connaît déjà ; lors d'un changement, lui laisser un temps la version familière.

## Traduction pour nos exercices
- **Postel** est déjà une règle de MINERVE : l'import JEMM et l'import de comptes rendus acceptent des fichiers « retouchés à la main » et produisent un format strict.
- **Doherty** : les écritures partagées (MELMIL, atelier) doivent **répondre à l'écran tout de suite**, même si l'enregistrement suit.
- **Jakob** : les sites d'exercice imitent des médias réels (TV4, BC1, ONU…) justement pour que les joueurs s'y retrouvent d'instinct.
- **Von Restorff** : une seule couleur d'alerte, rare, pour ce qui est vraiment urgent.
- **Peak-End** : soigner la **fin** d'un parcours (« CR téléchargé ✓ », « scénario lancé ✓ »).
