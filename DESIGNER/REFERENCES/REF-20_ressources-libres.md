# REF-20 — Boîte à outils de ressources libres (bradtraversy / design-resources-for-developers)

- **Source** : https://github.com/bradtraversy/design-resources-for-developers
- **Ingéré** : 2026-09-24. Liste d'outils à citer quand un besoin se présente ; ce n'est pas une doctrine.

| Besoin | Ressources libres |
|---|---|
| Polices | Google Fonts, Font Squirrel, FontPair |
| Couleurs | Coolors, Adobe Color, Color Hunt ; **Radix Colors** (REF-15) pour une échelle d'interface |
| Contraste | **whocanuse.com** (qui peut lire cette combinaison ?) |
| Icônes | **Lucide** (REF-08, en place), Feather, **Tabler Icons** (plus de 3 500), Simple Icons (logos de marques ⚠ réels) |
| Illustrations | unDraw, Humaaans, Open Peeps, DrawKit, IRA Design |
| Composants | Radix, Headless UI, Chakra UI, Mantine |
| Inspiration | One Page Love, Behance |

⚠ Les **logos de marques réelles** (Simple Icons) ne doivent **pas** servir sur des sites d'exercice publiés hors du périmètre d'exercice : règle anti-usurpation de MINERVE.
